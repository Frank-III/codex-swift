| Snapshot corpus and real-PTY matrix | Representative source-shaped snapshots plus real-PTY coverage are implemented for the actual application loop, render-only Observation invalidation, burst input and focus across history reset, mouse-origin rebasing, balanced keyboard protocols, dynamic-height overflow, app input, alternate key bindings, raw-mode suspend/resume around external processes, scrollback clearing, incremental Markdown holdback, interruption rewind, and ANSI backend reflow after live `TIOCSWINSZ` resize. Inline initialization now follows Ratatui Rust `ratatui-core/src/terminal/inline.rs::compute_inline_size`: probe before appending rows, compensate for bottom scrolling, start at column zero, clear before replacing resize diff buffers, and wait for delayed CPR and use a known absolute bottom-anchored viewport when CPR is unavailable, avoiding terminal-specific cursor-save drift. The normal view now follows Codex's retained-live-viewport plus committed-history model: newline-stable assistant/reasoning Markdown and finalized cells are inserted above the 22-row mutable composer/stream surface through TermLoom's host-specific native-history path. Standard terminals use bottom-margin CRLF; Supaterm/Zellij/tmux use unsynchronized whole-terminal output plus live-pane repaint, filling tall terminals and continuing into native scrollback without losing canonical source. The history write intentionally stays outside CSI `?2026`, because Ghostty-family hosts otherwise present the screen update without committing every displaced row to native scrollback. Physical width changes purge stale reflowed rows, reanchor at column zero, recreate backend diff buffers, and replay committed history from source, preventing duplicated cards and border fragments during rapid resize cycles. Codex screen regions use TermLoom Swift's `Layout` engine, and inline mouse capture is disabled so native terminal selection/copy remains available. Header/history rows now scroll out incrementally under tall bottom panes instead of disappearing or pinning, and the slash popup follows upstream composer → popup ordering, eight-item wrapped measurement, cyan selection, Up/Down and Ctrl-P/Ctrl-N navigation, Esc dismissal, Enter dispatch, and Tab or `/` completion |
